Results

Four ownership paths at the current inputs. Keep ICE runs each truck to its COE expiry then buys a matched new ICE. All-new ICE replaces the cohort now. Plan A and Plan B follow the per-truck actions. Recomputes live on any input change.

Signed credits reduce cost. Saving % = (Keep ICE total − plan total) / Keep ICE total. Target headroom = (1 − target) × Keep ICE total − plan total, where the saving target defaults to 15%. Full derivations in Methodology & assumptions below.

Break-even and sensitivity

Each slider changes one cost driver and recomputes every path through the same engine. These are mathematical break-even conditions, not quoted prices. The baseline is always the current Keep ICE total at the unchanged inputs.

Validation

The engine runs an independent reconciliation (the workbook's Review sheet) on every recompute. These are internal consistency checks, not a probability that a company will save money.

Reconciliation checkActualExpectedStatus

Numerical reconciliation is strong; company-fit confidence is low because ownership, prices, COEs and charger rights are not established in the demonstration data. A pass count is not a savings forecast.

Methodology & assumptions, sources and audit trail

The engine is deterministic: the same inputs always produce the same outputs, with no network, no randomness and no external service. The fixed horizon is 120 months (ten analysis years, 0 to 10). Demonstration inflation and discount are all zero, so year-band escalation is 1 and NPV equals nominal. "n.a." propagates whenever a gating input is missing (a per-truck input status that is not Complete, a site completeness that is not Complete, or a path count that does not equal the included truck count); the model never substitutes zero for an unknown.

Diesel visits        = ceiling(work km x available days x L/km / (refill litres - detour km x L/km))
Diesel quantity      = (productive km on available days + refuel visits x detour km) x L/km
EV grid intensity    = battery kWh/km / (1 - charging loss)
Public visits        = ceiling(public share x route/auxiliary grid demand
                               / (grid refill energy - public share x charger detour energy))
EV grid quantity     = productive route/auxiliary grid demand + public visits x detour energy
EV service / year    = (EV 200,000 km schedule total / 200,000) x EV km/year
Vehicle TCO          = current asset value + purchases + old/new operating + repairs + sale fees
                       - old-vehicle disposal - year-10 assets - conditional in-horizon vehicle grants
Site TCO             = initial installed cost + recurring cost + renewal + restoration - recovery
                       - checked charger grant   (counted once per plan)
Fleet TCO            = sum of truck-path vehicle TCO + shared site TCO
Saving %             = (Keep ICE total - plan total) / Keep ICE total
Target headroom      = (1 - target) x Keep ICE total - plan total          (target defaults to 15%)
Max site TCO target  = (1 - target) x Keep ICE total - plan vehicle TCO    (target defaults to 15%)
Horizon              = fixed 120 months; demo inflation = 0, demo discount = 0
