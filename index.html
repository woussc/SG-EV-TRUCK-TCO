Break-even & sensitivity

How to read these sliders

Each slider changes one of the most-critical cost drivers and recomputes every path through the same engine, redrawing the line and bar beside it live. These are mathematical break-even conditions, not quoted prices. The baseline is always the current Keep ICE total at the unchanged inputs. The discount rate is a rarely-changed assumption and lives in the Advanced assumptions area in the Inputs panel.

Average km cannot exceed peak km. A price change is a cost breakpoint, not a route-planning recommendation. The per-path figures and the saving-target headroom are in the Results breakdown table below.

Results breakdown

Four ownership paths at the current inputs. Keep ICE runs each truck to its COE expiry then buys a matched new ICE. All-new ICE replaces the cohort now. Plan A and Plan B follow the per-truck actions. Recomputes live on any input change. All figures to 2 decimal places.

Signed credits reduce cost. Saving % = (Keep ICE total − plan total) / Keep ICE total. Target headroom = (1 − target) × Keep ICE total − plan total, where the saving target defaults to 15%. Full derivations in Methodology & assumptions below.

Day-0 funding by path

Cash needed at day 0 for each path, with its components. n.a. is shown as n.a., never as a zero.

Day-0 funding = sum of the first-year vehicle cash outflows (Annual build col R) plus, for the EV plans, the year-0 charging-site cash. A negative component is a credit (a grant or disposal inflow) that reduces the cash needed.

Prospects

Prospects

Rank prospective customers by the two questions the business asks: who benefits most from switching to EV trucks, and who is the biggest account opportunity. Every number in the table is a model output from the same engine that drives the Results section; no heuristic weights, no adoption probabilities.

Each case is a full input set. The seeded cases are a set of Illustrative presets (not real customers): a fully-specified Best case whose charging-site quote and verification evidence are complete, so it passes every gate and shows what a confirmed win looks like (numeric Total economic TCO and a positive saving); a marginal Mid case and a negative-saving Bad case tuned from the same baseline; a prefilled Blank profile for starting a fresh client (common Singapore-market shared assumptions filled, customer-specific duty and quotes left blank, so Total economic TCO stays n.a. until the critical inputs are supplied). "Meets entered 15% target" mirrors the Results "Saving claim status" and is conditional on the supplied figures, not an adoption probability.

Cards are ranked by the selected sort. Benefit ranking uses best EV-plan Saving % vs Keep ICE; cases that fail entered limits or are diagnostic-only are flagged and sink to the bottom (they are not confirmed wins). Account ranking uses absolute 10-yr saving in S$; when a case has no confirmed numeric saving (for example the charging-site quote is not itemised so site cost stays n.a.) it falls back to the indicative vehicle-only benefit and is still flagged. Open a card’s Details for the exact model figures that drove its rank.

Load copies a prospect's full input set into the editable sections, so you can inspect or adjust it. Edits made do not change the saved prospect unless you duplicate it back.

Methodology & assumptions, sources and audit trail

The engine is deterministic: the same inputs always produce the same outputs, with no network, no randomness and no external service. The fixed horizon is 120 months (ten analysis years, 0 to 10). Default inflation and discount are all zero, so year-band escalation is 1 and NPV equals nominal. "n.a." propagates whenever a gating input is missing (a per-truck input status that is not Complete, a site completeness that is not Complete, or a path count that does not equal the included truck count); the model never substitutes zero for an unknown.

Diesel visits        = ceiling(work km x available days x L/km / (refill litres - detour km x L/km))
Diesel quantity      = (productive km on available days + refuel visits x detour km) x L/km
EV grid intensity    = battery kWh/km / (1 - charging loss)
Public visits        = ceiling(public share x route/auxiliary grid demand
                               / (grid refill energy - public share x charger detour energy))
EV grid quantity     = productive route/auxiliary grid demand + public visits x detour energy
EV service / year    = (EV 200,000 km schedule total / 200,000) x EV km/year
Vehicle TCO          = current asset value + purchases + old/new operating + repairs + sale fees
                       - old-vehicle disposal - year-10 assets - conditional in-horizon vehicle grants
Site TCO             = initial installed cost + recurring cost + renewal + restoration - recovery
                       - checked charger grant   (counted once per plan)
Fleet TCO            = sum of truck-path vehicle TCO + shared site TCO
Saving %             = (Keep ICE total - plan total) / Keep ICE total
Target headroom      = (1 - target) x Keep ICE total - plan total          (target defaults to 15%)
Max site TCO target  = (1 - target) x Keep ICE total - plan vehicle TCO    (target defaults to 15%)
Horizon              = fixed 120 months; demo inflation = 0, demo discount = 0
